## 🚀 系统行为

### 每小时（00:00 - 23:00）
1. 检查编译状态
2. 读取开发计划
3. 找到下一个待完成任务
4. 使用 Claude Code 开发（TDD 方法）
5. 运行测试验证
6. 自动提交代码
7. 更新 MEMORY.md

### 每6小时（00:00, 06:00, 12:00, 18:00）
- 快速状态检查
- 系统健康检查
- 编译状态验证
- 开发进度统计

### 每天 20:00
- 生成每日进度报告
- 发送到飞书

### 每天凌晨 02:00
- 自动备份代码和文档

## ⚠️ 注意事项

### 避免冲突
- ✅ 进度检查时间（00:00, 06:00, 12:00, 18:00）与备份（02:00）不冲突
- ✅ 每日报告（20:00）不影响开发任务执行

### 异常处理
- 如果 Claude Code 失败，记录日志继续下一个任务
- 如果编译失败，记录错误，不影响后续任务
- 如果测试失败，记录日志，不自动提交

### 监控建议
- 每日 20:00 查看进度报告
- 每周日 21:00 查看每周汇总
- 检查 `logs/` 目录下的日志文件
- 关注 `logs/cron_dev.log` 了解自动开发状态
