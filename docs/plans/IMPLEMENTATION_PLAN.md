## 2. 阶段详细计划

### P0-1: HAL + 启动 + 线程调度（W1-6）

**目标**: ARM64 启动到单核线程调度

#### W1-2: 硬件抽象层与启动

**HAL 平台层**
- ARM64 异常向量表（EL1）
- 系统寄存器访问封装
- 内存屏障宏（DMB/DSB/ISB）
- UART 早期输出

**多阶段启动**
- Bootloader: 硬件初始化、MMU 恒等映射、设备树解析
- 内核入口: 切换到详细页表映射
- 内核初始化: BSS 清零、对象池初始化

**交付物**:
- [ ] HAL 层: `kernel/arch/arm64/hal.c`
- [ ] 启动代码: `kernel/arch/arm64/boot.S`, `kernel/arch/arm64/entry.c`
- [ ] 异常向量: `kernel/arch/arm64/exception.S`
- [ ] 链接脚本: `lds/kernel.ld`

#### W3-4: 线程调度器

**256 级优先级调度器**
- 4×64 位位图 + CLZ 指令 O(1) 查找
- SCHED_FIFO + SCHED_RR
- 上下文切换（ARM64 寄存器保存/恢复）
- 线程创建/销毁/挂起/恢复

**交付物**:
- [ ] 调度器: `kernel/sched/scheduler.c`
- [ ] 线程管理: `kernel/sched/thread.c`
- [ ] 上下文切换: `kernel/arch/arm64/context.S`
- [ ] 单元测试: `tests/test_scheduler.c`

#### W5-6: 定时器与内核同步原语

**定时器管理**
- ARM 架构定时器（CNTVCT_EL0）
- 系统滴答、软件定时器、线程延迟
- 高精度时间戳（纳秒级）

**内核内部同步**
- Ticket Lock（公平自旋锁）
- 互斥锁（优先级继承/天花板）

**交付物**:
- [ ] 定时器: `kernel/sched/timer.c`
- [ ] 自旋锁: `kernel/sched/spinlock.c`
- [ ] 互斥锁: `kernel/sched/mutex.c`

**里程碑 M1**: 单核线程调度可用，线程切换 < 5μs

---

### P0-2: IPC 子系统（W7-10）

**目标**: 实现内核 IPC 机制，支持同步/异步消息传递

#### W7-8: IPC 核心机制

**同步消息传递（Send/Receive/Reply）**
- IPC 端点（Endpoint）内核对象
- 快速路径优化：同核直接上下文切换
- 寄存器传递小消息（≤ 4 寄存器）
- 阻塞/唤醒语义

**异步通知（Notification）**
- 通知对象内核对象
- 信号/等待语义
- 中断到线程通知

**交付物**:
- [ ] IPC 核心: `kernel/ipc/endpoint.c`
- [ ] 通知: `kernel/ipc/notification.c`
- [ ] 快速路径: `kernel/ipc/fast_path.c`
- [ ] 测试: `tests/test_ipc.c`

#### W9-10: Pulse 与通道-连接模型

**Pulse 轻量级消息**
- 优先级 + code + value 三元素
- 异步投递，发送方不阻塞
- 优先级保序

**通道-连接模型**
- ChannelCreate：服务端创建通道
- ConnectAttach：客户端附加到通道
- 消息头/负载分离

**交付物**:
- [ ] Pulse: `kernel/ipc/pulse.c`
- [ ] 通道连接: `kernel/ipc/channel.c`

**里程碑 M2**: IPC 可用，同核往返 < 1μs

---

### P0-3: 虚拟内存 + 对象管理（W11-16）

**目标**: 虚拟内存隔离 + 内核对象生命周期管理

#### W11-13: 虚拟内存管理

**页表管理**
- ARMv8-A 4 级页表（PGD → PUD → PMD → PTE）
- 4KB/2MB/1GB 混合页支持
- 页表分配/释放

**地址空间**
- 内核空间/用户空间隔离
- 多地址空间管理（每进程独立页表）
- 页面权限控制（R/W/X）
- 共享内存映射（通过能力授权）

**交付物**:
- [ ] 页表: `kernel/mm/page_table.c`
- [ ] 地址空间: `kernel/mm/vmspace.c`
- [ ] 共享内存: `kernel/mm/shmem.c`
- [ ] 测试: `tests/test_mm.c`

#### W14-16: 内核对象管理

**统一类型系统**
- KObjHeader_t 公共头部
- 10 种对象类型（线程/端点/通知/CSpace/VM空间/页帧/中断/设备/通道/连接）
- 运行时类型查询

**引用计数与级联销毁**
- 原子引用计数
- 父子关系追踪
- 引用归零时级联释放子对象

**对象池（Souls 分配器）**
- 固定大小对象池，O(1) 分配/释放
- 无碎片、无动态分配
- 泄漏检测（枚举活跃对象）

**延迟释放（RCU 风格）**
- 并发安全释放
- 宽限期等待
- 无悬挂指针

**交付物**:
- [ ] 对象类型: `kernel/kobj/kobject.c`
- [ ] 对象池: `kernel/kobj/object_pool.c`
- [ ] 引用计数: `kernel/kobj/refcount.c`
- [ ] 延迟释放: `kernel/kobj/deferred_free.c`

**里程碑 M3**: 虚拟内存隔离完成，内核对象管理可用

---

### P0-4: 能力系统 + 安全基座（W17-22）

**目标**: 细粒度能力访问控制 + 安全基础设施

#### W17-19: 能力（Capability）系统

**能力空间（CSpace）**
- 每进程独立 CSpace
- 能力表管理（创建/查找/删除）

**能力操作**
- Cap_Copy：复制（可降权）
- Cap_Move：移动
- Cap_Revoke：级联撤销
- Cap_Delete：删除
- 权限验证（读/写/执行/转发/撤销）

**交付物**:
- [ ] 能力管理: `kernel/cap/capability.c`
- [ ] CSpace: `kernel/cap/cspace.c`
- [ ] 测试: `tests/test_capability.c`

#### W20-22: 安全基座

**安全机制**
- 页面权限强制（R/W/X）
- 内核代码段只读保护
- 栈溢出保护（金丝雀 + MPU 保护页）
- 安全启动链（签名验证框架）

**交付物**:
- [ ] 安全保护: `kernel/mm/security.c`
- [ ] 栈保护: `kernel/sched/stack_guard.c`
- [ ] 安全启动: `kernel/arch/arm64/secure_boot.c`

**里程碑 M4**: 能力访问控制可用，安全基座完成

---

### P0-5: SMP 多核 + 中断路由（W23-28）

**目标**: 多核支持 + 中断到用户态投递

#### W23-25: SMP 多核

**多核启动**
- 主核启动从核（PSCI/SMP 协议）
- 每 CPU 数据区初始化
- 从核调度器启动

**多核调度**
- 每 CPU 就绪队列
- 负载均衡（工作窃取）
- 线程迁移 + CPU 亲和性
- 核心 IPI（Reschedule/Stop/Call）

**交付物**:
- [ ] SMP 启动: `kernel/arch/arm64/smp_boot.c`
- [ ] 多核调度: `kernel/sched/smp.c`
- [ ] IPI: `kernel/arch/arm64/ipi.c`

#### W26-28: 中断路由

**GIC 驱动**
- GIC-400/500 初始化
- 中断优先级管理
- 中断亲和性配置

**中断到用户态**
- InterruptAttach：绑定中断到通知对象
- InterruptWait：用户态线程等待中断
- 中断 → 内核路由 → Notification → 用户态线程

**交付物**:
- [ ] GIC 驱动: `kernel/arch/arm64/gic.c`
- [ ] 中断路由: `kernel/irq/interrupt.c`
- [ ] 测试: `tests/test_irq.c`

**里程碑 M5**: 1-8 核 SMP 可运行，中断可路由到用户态

---

### P0-6: 用户态核心服务（W29-36）

**目标**: 实现核心用户态服务，系统可自举

#### W29-31: 用户态基础设施

**libkernel（系统调用库）**
- 所有系统调用的 C 语言绑定
- 系统调用桩代码（SVC 调用封装）

**用户态启动（init 服务）**
- 内核启动第一个用户态线程
- init 服务启动其他核心服务

**交付物**:
- [ ] 系统调用库: `lib/libkernel/syscall.c`
- [ ] init 服务: `services/init/main.c`

#### W32-34: 核心管理器

**ProcessManager（进程管理器）**
- 进程创建/销毁/监控
- 进程间资源隔离
- 通过 IPC 提供服务

**MemoryManager（内存管理器）**
- 物理内存池管理
- 虚拟地址映射服务
- 共享内存协调

**PathManager（路径管理器）**
- 设备路径命名空间
- 服务注册与发现

**交付物**:
- [ ] ProcessManager: `services/proc/`
- [ ] MemoryManager: `services/mem/`
- [ ] PathManager: `services/path/`

#### W35-36: 用户态驱动框架

**基础驱动服务**
- MMIO 映射（通过能力授权）
- DMA 缓冲区管理
- 中断绑定与处理

**示例驱动**
- UART 驱动（用户态）
- GPIO 驱动（用户态）

**交付物**:
- [ ] 驱动框架: `services/dev/driver_framework.c`
- [ ] UART 驱动: `drivers/native/uart.c`

**里程碑 M6**: 核心服务可自举，用户态驱动可运行
