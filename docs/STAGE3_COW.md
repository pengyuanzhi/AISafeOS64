# EXT4 Stage 3: 写时复制（CoW）

## 开发计划

### 1. CoW 数据结构设计（1周）

#### 任务清单
- [ ] 定义 CoW 块引用计数结构
- [ ] 定义快照元数据结构
- [ ] 定义 CoW 块映射结构
- [ ] 定义快照命名空间结构

#### 技术要点
- 块引用计数：跟踪每个块被多少快照引用
- 快照元数据：包含快照 ID、创建时间、父快照等
- CoW 块映射：记录原始块和 CoW 块的映射关系

### 2. 快照创建机制（1周）

#### 任务清单
- [ ] 原子创建快照接口
- [ ] 快照与当前文件系统的关联
- [ ] 快照命名空间管理
- [ ] 快照元数据持久化

#### 技术要点
- 使用 Journal 确保快照创建的原子性
- 快照标记和标识符管理
- 快照的元数据存储和读取

### 3. 快照回滚机制（1周）

#### 任务清单
- [ ] 原子回滚到快照接口
- [ ] 释放 CoW 块
- [ ] 快照清理机制
- [ ] 回滚错误处理

#### 技术要点
- 回滚时的原子性保证
- CoW 块的引用计数管理
- 快照的删除和清理

### 4. CoW 性能优化（1周）

#### 任务清单
- [ ] CoW 块预分配优化
- [ ] 快照克隆优化
- [ ] 并发快照创建优化
- [ ] 内存占用优化

#### 技术要点
- CoW 块分配策略优化
- 减少不必要的 CoW 操作
- 内存池管理

## 开发流程

### TDD 方法
1. RED: 编写测试
2. GREEN: 最小实现
3. REFACTOR: 重构优化

### 验收标准
- [ ] 所有单元测试通过
- [ ] CoW 功能正常工作
- [ ] 快照创建和回滚功能正常
- [ ] 代码符合 MISRA C:2012
- [ ] text 段大小检查（< 50KB）
