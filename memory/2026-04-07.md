# 2026-04-07 开发记录

## HAL 层接口抽离完成 ✅ (13:05)

**commit**: `280248e` refactor(hal): 体系架构独立性重构 - 所有内核核心代码迁移到 HAL 接口

### 重构内容
将内核核心代码（kernel/ 非 arch/ 目录）中所有 ARM64 特定操作抽离到 HAL 层:

| 模块 | 文件 | 抽离内容 | HAL 接口 |
|------|------|---------|----------|
| 定时器 | timer.c | mrs cntpct/cntfrq/cntp_ctl, msr cntp_cval/cntp_ctl | hal_timer_get_* / hal_timer_set_* |
| 调度器 | scheduler.c | wfe (5处) | hal_wfe() |
| 线程 | thread.c | wfe (2处) | hal_wfe() |
| IPC | ic2.c | dmb ish/ishst/ishld (3处) | hal_dmb_ish/ishst/ishld() |
| 虚拟内存 | vmspace.c | msr ttbr0_el1 + isb | hal_write_ttbr0() |
| 页表 | page_table.c | mrs/msr ttbr0/ttbr1, tlbi (9处) | hal_read/write_ttbr* / hal_tlb_* |

新增 HAL 接口 14 个。kernel/ 非 arch/ 目录零体系架构违规。text=26,506 bytes。

## 用户态 EL0 QEMU 端到端验证 ✅ (20:26)

**commit**: `06ca74a` feat(user): 用户态EL0 QEMU端到端验证 - SVC/IPC/Capability/地址空间隔离

### 验证通过的路径
- EL1 → EL0 降级 (eret + SPSR=0x0 EL0t)
- SVC 系统调用 (svc #0 → exception.S → syscall_handler)
- SYS_DEBUG_PRINT (EL0 通过 SVC 打印)
- SYS_THREAD_GET_ID (EL0 通过 SVC 获取线程 ID)
- SYS_THREAD_EXIT (EL0 通过 SVC 退出线程)
- IPC send/recv (两个 EL0 线程通过 channel 通信)
- Capability (EL0 通过 SVC 创建/操作 cspace)
- 用户态地址空间隔离 (Data Abort 验证隔离生效)

### 修改的文件 (8个)
1. **exception.S** — EL0 异常向量 (SVC + IRQ)
2. **context.S** — 用户态上下文初始化
3. **entry.c** — EL0 测试线程 (user_test_entry) + IPC/CAP 测试
4. **thread.h** — TCB 添加 is_user/user_sp 字段
5. **syscall_dispatch.c** — 实现 SYS_THREAD_EXIT
6. **mmu.c** — mmu_create_user_pgd + mmu_switch_to_user/kernel
7. **scheduler.c** — 上下文切换时 TTBR0 切换
8. **include/kernel/syscall.h** — syscall0/1/2/3 inline helper
