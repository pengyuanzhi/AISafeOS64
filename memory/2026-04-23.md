**目标**: 将体系架构相关代码从 kernel/ 移至 arch/，确保内核核心代码的体系架构独立性

- 新增 `hal_dsb_ish()` - 数据同步屏障 (Inner Shareable)

## 架构成果

### HAL 接口清单

**定时器接口** (5 个)
- `hal_timer_get_count()` - 读取物理定时器计数值
- `hal_timer_get_freq()` - 读取物理定时器频率
- `hal_timer_get_control()` - 读取物理定时器控制寄存器
- `hal_timer_set_compare()` - 设置物理定时器比较值
- `hal_timer_set_control()` - 设置物理定时器控制寄存器

**内存屏障接口** (3 个)
- `hal_dmb_ish()` - 数据内存屏障 (Inner Shareable)
- `hal_dmb_ishst()` - 数据内存屏障 (Inner Shareable, Store)
- `hal_dmb_ishld()` - 数据内存屏障 (Inner Shareable, Load)

**数据同步屏障接口** (2 个)
- `hal_dsb_ish()` - 数据同步屏障 (Inner Shareable)
- `hal_dsb_sy()` - 数据同步屏障 (Full System)

**页表接口** (5 个)
- `hal_read_ttbr0()` - 读取 TTBR0_EL1 寄存器
- `hal_read_ttbr1()` - 读取 TTBR1_EL1 寄存器
- `hal_write_ttbr0()` - 写入 TTBR0_EL1 寄存器
- `hal_write_ttbr1()` - 写入 TTBR1_EL1 寄存器
- `hal_tlb_invalidate_asid()` - 刷新指定 ASID 的 TLB
- `hal_tlb_invalidate_all()` - 使整个 TLB 无效

**低功耗接口** (2 个)
- `hal_wfe()` - 等待事件 (低功耗 WFE)
- `hal_wfi()` - 等待中断 (低功耗 WFI)
- `hal_sev()` - 发送事件

**CPU 信息接口** (2 个)
- `hal_get_cpu_id()` - 获取 CPU ID
- `hal_get_current_el()` - 获取当前异常级别

**中断控制接口** (5 个)
- `hal_irq_enable()` - 启用 IRQ 中断
- `hal_irq_disable()` - 禁用 IRQ 中断
- `hal_irq_disable_all()` - 禁用所有中断
- `hal_irq_saved_state()` - 获取中断状态
- `hal_irq_restore()` - 恢复中断状态

**缓存维护接口** (3 个)
- `hal_dcache_clean()` - 清理数据缓存到内存
- `hal_dcache_invalidate()` - 使数据缓存无效
- `hal_dcache_clean_and_invalidate()` - 清理并使数据缓存无效

**UART 接口** (5 个)
- `hal_uart_init()` - 初始化 UART
- `hal_uart_putc()` - UART 发送单个字符
- `hal_uart_puts()` - UART 发送字符串
- `hal_uart_getc()` - UART 接收单个字符
- `hal_uart_enable_rx_irq()` - 使能 UART 接收中断

**异常返回接口** (4 个)
- `hal_read_elr()` - 读取 ELR_EL1
- `hal_write_elr()` - 写入 ELR_EL1
- `hal_read_spsr()` - 读取 SPSR_EL1
- `hal_write_spsr()` - 写入 SPSR_EL1
- `hal_isb()` - 指令同步屏障

**总计**: 38 个 HAL 接口
