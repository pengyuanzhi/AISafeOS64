## 完成工作

### 体系架构分层优化

检查并完善了内核核心代码中的体系架构分层，确保所有非 arch 目录的代码都通过 HAL 接口访问硬件。

**1. Timer 寄存器访问 HAL 抽象**

修改 `kernel/arch/arm64/entry.c` 文件，将直接访问 timer 寄存器的 `__asm__` 指令替换为 HAL 接口：

- 将 `__asm__ volatile("msr cntp_ctl_el0, %0" :: "r"((uint64_t)0U));` 替换为 `hal_timer_set_control(0ULL);`
- 将 `__asm__ volatile("mrs %0, cntpct_el0" : "=r"(current));` 替换为 `current = hal_timer_get_count();`
- 将 `__asm__ volatile("mrs %0, cntfrq_el0" : "=r"(freq));` 替换为 `freq = hal_timer_get_freq();`
- 将 `__asm__ volatile("msr cntp_cval_el0, %0" :: "r"(current + delta));` 替换为 `hal_timer_set_compare(current + delta);`
- 将 `__asm__ volatile("msr cntp_ctl_el0, %0" :: "r"((uint64_t)1U));` 替换为 `hal_timer_set_control(1ULL);`
