## 📝 详细设计

### 1. 嵌套页表（NPT）设计

**数据结构**：
```c
typedef struct {
    paddr_t    root_paddr;         /* 根页表物理地址 */
    vaddr_t    root_vaddr;         /* 根页表虚拟地址 */
    uint64_t   guest_phys_base;    /* Guest 物理地址基 */
    uint64_t   guest_phys_size;    /* Guest 物理地址空间大小 */
    uint32_t   ref_count;          /* 引用计数 */
} nested_page_table_t;
```

**页表项操作**：
- 设置页表项：`set_pte(pt, addr, flags)`
- 清除页表项：`clear_pte(pt)`
- 读取页表项：`read_pte(pt)`

**页表遍历**：
- 两级页表：`pt[索引1][索引2]`
- 三级页表：`pt[索引1][索引2][索引3]`

**地址转换**：
```
Guest VA → Guest PA → Host PA
    ↓              ↓              ↓
  Stage-1       Stage-2          Host 物理地址
  (TTBR0/TTBR1)  (Guest PA)          页表项
    ↓              ↓              ↓
  IPA           映射关系          物理页帧
```

**TLB 刷新**：
- 刷新所有 TLB：`tlbi vmalle1is`
- 刷新特定地址：`tlbi vaae1is, addr`
- 同步指令：`dsb ish`, `isb`

### 2. 虚拟 GIC（VGIC）设计

**中断状态机**：
```
INACTIVE → PENDING → ACTIVE → ACTIVE_PENDING → INACTIVE
                ↓           ↓
            INACTIVE    INACTIVE
```

**中断注入**：
1. 设置 VGIC 中断状态为 PENDING
2. 设置中断使能位
3. 设置 vCPU 待注入中断
4. 检查 vCPU 是否在 WFI 状态
5. 如果是，发送虚拟中断

**中断路由**：
- SPI: 共享外设中断
- PPI: 私有外设中断
- SGI: 软件生成中断
- ID 0-15: SGI
- ID 16-31: PPI
- ID 32-1019: SPI

**中断优先级**：
- 优先级：0-255（255 最高）
- 优先级分组
- 优先级提升

**中断去激活**：
- Guest 写入 EOIR
- 清除中断激活状态
- 发送中断完成
