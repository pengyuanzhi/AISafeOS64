- **修复**: 用 `__asm volatile("wfe")` 替换
- **修改文件**: tests/test_smp.c

**问题 5: 头文件包含错误**
- **原因**: dev_t, ino_t 等类型未定义

- **修改文件**: lib/musl_aisafe/arch/aarch64_aisafe/bits/stat.h

**问题 6: kstat.h 头文件包含错误**
- **原因**: blksize_t, blkcnt_t 等类型未定义
- **修复**: 添加 `#include <sys/types.h>` 和 `#include <time.h>`
- **修改文件**: lib/musl_aisafe/arch/aarch64_aisafe/kstat.h
