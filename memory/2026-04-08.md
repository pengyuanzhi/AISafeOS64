## EL0 用户态端到端验证（重大突破）✅ (~12:30)

### 发现并修复的多个关键 Bug

#### Bug 1: TTBR1 PGD 索引计算错误
- **症状**: EL0 eret 后 Prefetch Abort at PC=0
- **根因**: `0xFFFF0000_4000xxxx` 的 PGD 索引是 0（不是 257），但用户 PGD 只复制了高 256 entries
- **修复**: `mmu_create_user_pgd()` 也复制 `s_pgd_ttbr1[0]`

#### Bug 2: context_switch 不保存 ELR_EL1/SPSR_EL1
- **症状**: SVC 返回后 ELR 指向错误地址（TTBR0 低地址而非 TTBR1 高地址）
- **根因**: `context_switch` 只保存 callee-saved (x19-x28)，不保存 ELR/SPSR。IRQ 在 EL0 触发时硬件保存 ELR/SPSR 到 ELR_EL1/SPSR_EL1，但 `context_switch` 切换线程后 ELR/SPSR 被覆盖
- **修复**: `schedule()` 中在 `context_switch` 前保存 ELR/SPSR 到 context[13]/[14]，恢复后从 next context 写回

#### Bug 3: EL0 代码地址空间错误
- **症状**: eret 后 Instruction Abort at 0x4000xxxx（TTBR0 低地址）
- **根因**: `user_entry_trampoline` 链接在 0x4000xxxx（TTBR0），但用户 PGD 的 TTBR0 为空
- **修复**: `create_user_test_thread()` 中将 entry 和 trampoline 地址加 `0xFFFF000000000000` 偏移转为 TTBR1 高地址

#### Bug 4: TTBR1 PTE 缺少 EL0 权限
- **症状**: EL0 通过 TTBR1 取指失败
- **根因**: TTBR1 PUD[1] 是 1GB 块映射，AP=RW（EL0 无权限）+ UXN
- **修复**: TTBR1 PUD[1] 改为指向 PMD→PTE 表，text 段用 PTE_AP_USER_RO

#### Bug 5: device_unregister 引用计数
- `device_unregister` 未递减 `drv->device_count` → 驱动无法注销

### schedule() ELR/SPSR 保存修复 (关键)

```c
/* 保存当前 ELR/SPSR 到 prev context */
__asm__ volatile("mrs %0, elr_el1" : "=r"(prev->context[13]));
__asm__ volatile("mrs %0, spsr_el1" : "=r"(prev->context[14]));

context_switch(prev->context, next->context);

/* 恢复 next 的 ELR/SPSR */
__asm__ volatile("msr elr_el1, %0" : : "r"(next->context[13]));
__asm__ volatile("msr spsr_el1, %0" : : "r"(next->context[14]));
```

这确保 EL0 线程被 tick 中断抢占后，ERET 能正确返回到 EL0 的 PC。

### context.S user_entry_trampoline 修改
不再需要 eret 路径——`schedule()` 的 eret（通过 irq handler 的 eret）处理 EL0 降级。

### 用户 PGD 映射架构
```
用户 PGD (TTBR0):
  [0] = s_pgd_ttbr1[0] → s_pud_ttbr1 (复制 TTBR1 映射)
  [1..255] = 空
  [256..511] = s_pgd_ttbr1[256..511] (TTBR1 高地址镜像)

EL0 代码通过 TTBR1 高地址 (0xFFFF0000_4000xxxx) 执行:
  PGD[0] → PUD[1] → PMD[0] → PTE 表 (text: RX, rodata: R--, data: RW-)
```
