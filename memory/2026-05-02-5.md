### VMA 树结构优化（链表 → 红黑树）

将虚拟内存区域（VMA）的管理从链表优化为红黑树，显著提升查找、插入和删除的效率。

**1. 红黑树数据结构实现**

- **红黑树头文件（include/kernel/rbtree.h）**
  - 红黑树节点结构（rb_node_t）
  - 红黑树根节点结构（rb_root_t）
  - 红黑树颜色枚举（RB_COLOR_RED/RB_COLOR_BLACK）
  - 红黑树旋转函数（左旋/右旋）
  - 红黑树修复函数（插入/删除后重新平衡）
  - 红黑树操作函数声明（插入/删除/查找/遍历）

- **红黑树实现文件（kernel/mm/rbtree.c）**
  - rb_insert(): 红黑树插入节点，复杂度 O(log n)
  - rb_delete(): 红黑树删除节点，复杂度 O(log n)
  - rb_search(): 红黑树查找节点，复杂度 O(log n)
  - rb_first(): 查找最小节点，复杂度 O(log n)
  - rb_last(): 查找最大节点，复杂度 O(log n)
  - rb_next()/rb_prev(): 中序遍历，复杂度 O(log n)

**2. VMA 结构优化**

修改 VMA 结构：
```c
typedef struct
{
    vaddr_t         start;          /**< @brief 起始虚拟地址（页对齐） */
    vaddr_t         end;            /**< @brief 结束虚拟地址（页对齐，不含） */
    uint32_t        flags;          /**< @brief 权限标志位 */
    vma_type_t      type;           /**< @brief VMA 类型 */
    paddr_t         phys_base;      /**< @brief 对应的物理地址基址（直接映射时） */
    kobj_id_t       shmem_id;       /**< @brief 共享内存对象 ID（VMA_TYPE_SHARED） */
    struct rb_node  rb_node;        /**< @brief VMA 红黑树节点 */  // ← 从链表节点改为红黑树节点
} vma_t;
```

修改地址空间结构：
```c
typedef struct
{
    page_table_t    *pgd;           /**< @brief 顶层页表（L0） */
    asid_t          asid;           /**< @brief 地址空间标识 */
    uint32_t        vma_count;      /**< @brief VMA 数量 */
    struct rb_root  vma_rb_root;    /**< @brief VMA 红黑树根 */  // ← 从链表改为红黑树
    vaddr_t         brk_base;       /**< @brief 堆基址 */
    vaddr_t         brk_current;    /**< @brief 当前堆顶 */
    vaddr_t         stack_top;      /**< @brief 栈顶地址 */
    uint32_t        ref_count;      /**< @brief 引用计数（共享地址空间） */
    TicketLock_t    lock;           /**< @brief 地址空间锁 */
} vm_space_t;
```

**3. VMA 比较函数**

- `vma_compare()`: 用于红黑树查找，按 start 地址比较
  - 返回 <0 如果 key < node->start
  - 返回 0 如果 key 在 [start, end) 内
  - 返回 >0 如果 key >= node->end

- `vma_less()`: 用于红黑树插入，按 start 地址比较
  - 返回 true 如果 node_a < node_b

**4. VMA 操作优化**

- `vmspace_find_vma()`: 使用红黑树查找 VMA，复杂度从 O(n) 降低到 O(log n)
  ```c
  struct rb_node *node = rb_search(&space->vma_rb_root, &vaddr, vma_compare);
  ```

- `vmspace_map()`: 使用红黑树插入 VMA，复杂度从 O(n) 降低到 O(log n)
  ```c
  rb_insert(&space->vma_rb_root, &vma->rb_node, vma_less);
  ```

- `vmspace_destroy()`: 使用红黑树遍历 VMA，复杂度 O(n log n)
  ```c
  struct rb_node *rb_node = rb_first(&space->vma_rb_root);
  while (rb_node != NULL) {
      rb_delete(&space->vma_rb_root, rb_node);
      rb_node = rb_next(rb_node);
  }
  ```

- `vmspace_unmap()`: 使用红黑树删除 VMA，复杂度从 O(n) 降低到 O(log n)
  ```c
  rb_delete(&space->vma_rb_root, &vma->rb_node);
  ```

### 技术特点

1. **红黑树性质** - 自动平衡，保证最坏情况下的性能
2. **查找优化** - 查找复杂度从 O(n) 降低到 O(log n)
3. **内存优化** - 红黑树节点内存开销小（4 个指针 + 颜色）
4. **线程安全** - 使用地址空间锁保护红黑树操作
5. **向后兼容** - VMA API 不变，内部实现优化
