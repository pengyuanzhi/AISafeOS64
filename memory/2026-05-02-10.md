## 架构设计

### 1. 核心原理

**Buddy System** 采用以下原理：
1. **按 2 的幂次方分割**物理内存块
2. **Buddy 合并**：相同大小的 buddy 可以合并成更大的块
3. **碎片整理**：自动合并空闲的 buddy 块
4. **与 Slab 缓存配合**：处理小块内存分配

### 2. 数据结构

**Buddy Node（块节点）**：
- 状态：空闲或已分配
- 基址：块起始物理地址
- 大小：块大小（2^order）
- 父节点：用于合并操作
- 左子节点：分割后的子块
- 右子节点：分割后的子块

**Buddy System（根结构）**：
- nodes 数组：所有块节点
- total_pages：总页数
- free_pages：空闲页数
- allocated_pages：已分配页数
- total_allocations：总分配次数
- total_frees：总释放次数
- fragmentation_count：碎片计数

### 3. 关键算法

#### Buddy 合并算法
```c
paddr_t buddy_find_buddy(paddr_t base, uint32_t order)
{
    return base ^ (1U << order);
}
```
- 使用异或操作找到 buddy 地址
- 地址相同的位表示 buddy 关系

#### Buddy 分割算法
1. 找到足够的空闲节点
2. 计算子块大小
3. 分割块为两个相同大小的子块
4. 更新父子节点关系

#### 碎片整理算法
1. 遍历所有块
2. 对每个空闲块尝试合并
3. 合并所有连续的空闲 buddy 块
4. 更新碎片计数

### 4. 性能特点

**优点**：
- ✅ 快速的内存分配/释放
- ✅ 减少外部碎片
- ✅ 支持大块内存分配
- ✅ 自动碎片整理

**缺点**：
- ⚠️ 内部碎片可能较大
- ⚠️ 与 Slab 缓存配合使用
- ⚠️ 复杂度较高

## 使用示例

### 初始化 Buddy System
```c
buddy_system_t sys;

/* 初始化 Buddy System（假设有 1024 页内存） */
buddy_system_init(&sys, 0x40000000, 1024);
```

### 分配内存
```c
/* 分配 1KB 内存 */
paddr_t addr = buddy_system_alloc(&sys, 1024);

/* 分配 4KB 内存 */
addr = buddy_system_alloc(&sys, 4096);
```

### 释放内存
```c
/* 释放 1KB 内存 */
buddy_system_free(&sys, addr, 1024);

/* 释放 4KB 内存 */
buddy_system_free(&sys, addr, 4096);
```

### 碎片整理
```c
/* 整理碎片 */
buddy_system_defragment(&sys);
```

### 获取统计信息
```c
uint32_t total_pages, free_pages, allocated_pages;

buddy_system_get_stats(&sys,
                       &total_pages,
                       &free_pages,
                       &allocated_pages,
                       NULL, NULL, NULL);
```
