## 架构设计

### 1. VM 生命周期管理

```
VM 创建流程：
vmm_create_vm() → 分配 VM 描述符 → 初始化 NPT → 初始化 VGIC → 返回 VM ID

VM 销毁流程：
vmm_destroy_vm() → 停止所有 vCPU → 释放 NPT → 释放 VGIC → 清除 VM 描述符

vCPU 生命周期：
创建 → 运行 → 退出 → 暂停/销毁
```

### 2. 嵌套页表（NPT）架构

```
Guest VA (2^48) → Guest PA (2^32) → Host PA (2^48)
    ↓                    ↓                    ↓
  Stage-1            Stage-2 (Guest PA)   Host 物理地址
  (TTBR0/TTBR1)         NPT 根页表            页表项
    ↓                    ↓                    ↓
  IPA                 映射关系                物理页帧
```

### 3. VM 退出处理流程

```
VM 运行 → vCPU 运行 → 触发退出 →
  ↓
  检查退出原因 (ESR[26:31])
  ↓
  分发到处理函数：
  - WFI/WFE → 等待中断
  - HVC → Hypercall
  - MMIO → 设备读写
  - 其他 → 跳过
  ↓
  更新 x 寄存器
  ↓
  继续运行（或不继续）
```

### 4. 虚拟设备架构

```
MMIO 访问 → vmm_handle_mmio() → 检查地址范围 →
  ↓
  调用设备回调 (read_fn/write_fn)
  ↓
  设备处理逻辑
  ↓
  返回结果
```
