# 一种基于自适应均衡间隔的多核任务迁移控制方法

## 技术领域
本发明涉及多核实时操作系统的负载均衡控制，具体涉及一种基于负载差异动态调整均衡间隔的任务迁移方法。

## 背景技术
传统固定周期均衡策略在负载平稳时会产生额外开销，在负载突变时又可能响应滞后，难以在实时与吞吐之间取得稳定平衡。

## 发明内容
本发明根据各 CPU 的负载差异动态调整均衡周期：当负载失衡扩大时缩短均衡间隔，当负载趋稳时延长均衡间隔。该机制可在有限控制开销下提升多核资源利用率。

本发明的有益效果在于：
1. 降低无效均衡次数。
2. 提高负载突变时的响应速度。
3. 控制均衡开销的上界。

## 具体实施方式
在一种实施方式中，系统周期性统计各 CPU 就绪线程数，并计算平均负载。当某 CPU 的负载显著高于平均负载时，将该 CPU 的均衡间隔缩短到原值的一半；当整体负载恢复平稳时，将均衡间隔逐步放大到上限。均衡触发时，仅从最忙 CPU 向最闲 CPU 迁移限定数量的线程。

## 权利要求骨架
1. 一种基于自适应均衡间隔的多核任务迁移控制方法，其特征在于，根据负载差异动态调整负载均衡触发周期。
2. 根据权利要求1所述的方法，其中负载失衡加剧时缩短均衡间隔。
3. 根据权利要求1所述的方法，其中负载恢复平稳时延长均衡间隔。
4. 根据权利要求1所述的方法，其中每次均衡的迁移数量受上限约束。
