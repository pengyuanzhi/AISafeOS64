# 一种实时任务与非实时任务分离的多核调度隔离方法

## 技术领域
本发明涉及多核实时操作系统的任务隔离与调度控制，具体涉及实时任务与普通任务的路径分离方法。

## 背景技术
在同一调度域中混合运行实时任务与普通任务，容易因负载均衡、工作窃取和迁移引入不可预测抖动，破坏实时性要求。

## 发明内容
本发明将任务分为实时任务和非实时任务两类：实时任务固定绑定到指定 CPU 分区，仅允许本地抢占；非实时任务允许参与迁移、负载均衡和工作窃取。调度器仅对非实时路径执行动态优化。

本发明的有益效果在于：
1. 实时任务与普通任务互不干扰。
2. 实时路径的执行模型简单且可验证。
3. 系统兼顾确定性与整体吞吐。

## 具体实施方式
在一种实施方式中，任务创建时标记其是否为实时任务。若为实时任务，则分配固定 CPU 亲和集合，并禁止自动迁移和窃取；若为非实时任务，则可以在调度压力和负载均衡策略下迁移到其他在线 CPU。调度器在 tick 中仅对实时任务执行固定优先级抢占，不在实时路径中执行全局均衡。

## 权利要求骨架
1. 一种实时任务与非实时任务分离的多核调度隔离方法，其特征在于，将实时任务限制在固定 CPU 分区内运行。
2. 根据权利要求1所述的方法，其中实时任务禁止自动迁移。
3. 根据权利要求1所述的方法，其中非实时任务允许参与负载均衡与工作窃取。
4. 根据权利要求1所述的方法，其中实时路径不包含全局扫描。
