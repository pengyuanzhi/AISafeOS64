# 一种同步消息事务的阻塞、超时与回复统一状态机方法

## 技术领域
本发明涉及微内核同步 IPC 的事务控制，具体涉及一种统一处理阻塞、超时和回复的状态机方法。

## 背景技术
同步消息传递通常包含发送、接收和回复多个阶段，若各阶段分别实现，容易造成状态不一致、超时处理复杂以及消息回收不完整。

## 发明内容
本发明将同步 IPC 抽象为统一事务状态机，消息在端点对象上经历阻塞发送、阻塞接收、回复和超时退避等状态转移，由统一状态机进行调度和恢复。

本发明的有益效果在于：
1. 统一消息生命周期管理。
2. 简化超时和回复的状态一致性控制。
3. 降低消息丢失和误唤醒风险。

## 具体实施方式
在一种实施方式中，端点对象保存当前发送者、等待者和待处理消息队列。发送方进入端点后，若接收方未就绪，则消息进入阻塞状态并挂入等待队列；若设置超时，则由定时器驱动状态机从阻塞态转入超时态并回收资源；接收方读取消息后，回复路径将事务状态推进到完成态。

## 权利要求骨架
1. 一种同步消息事务的阻塞、超时与回复统一状态机方法，其特征在于，端点对象通过统一状态机管理消息事务生命周期。
2. 根据权利要求1所述的方法，其中发送、接收和回复共享同一状态转换逻辑。
3. 根据权利要求1所述的方法，其中超时事件驱动事务回收。
4. 根据权利要求1所述的方法，其中阻塞队列与回复队列分别由端点对象维护。
