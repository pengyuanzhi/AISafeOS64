# 一种具备保留阈值约束的多核工作窃取调度方法

## 技术领域
本发明涉及多核调度中的工作窃取机制，具体涉及一种带源核保留阈值的任务窃取方法。

## 背景技术
常规工作窃取在空闲核出现时直接从忙碌核获取任务，容易削弱源核局部稳定性，并带来不可控迁移开销，不适合实时任务混合场景。

## 发明内容
本发明设置源核最低保留任务数，只有当源核任务量高于该阈值时，空闲核才可发起窃取；窃取对象优先选择源核最高优先级链表尾部的任务，以提高缓存局部性。

本发明的有益效果在于：
1. 防止源核被过度掏空。
2. 降低对正在运行任务的扰动。
3. 兼顾调度均衡和缓存效率。

## 具体实施方式
在一种实施方式中，当某 CPU 的本地就绪队列为空时，调度器扫描其他在线 CPU，选择任务数量最多的 CPU 作为源核。如果源核的运行任务数高于预设保留阈值，则从其最高优先级链表尾部取出一个线程并加入当前 CPU 队列；否则不执行窃取。该方法避免源核被清空导致的实时抖动。

## 权利要求骨架
1. 一种具备保留阈值约束的多核工作窃取调度方法，其特征在于，空闲 CPU 仅在源 CPU 保留至少预设任务数后才窃取任务。
2. 根据权利要求1所述的方法，其中窃取对象来自源队列尾部。
3. 根据权利要求1所述的方法，其中窃取仅在当前 CPU 队列为空时触发。
4. 根据权利要求1所述的方法，其中源核任务数低于阈值时拒绝窃取。
