# 一种面向硬实时微内核的按 CPU 分区固定优先级位图调度方法

## 技术领域
本发明涉及多核实时操作系统调度技术，具体涉及一种按 CPU 分区组织的固定优先级位图调度方法。

## 背景技术
传统全局调度器依赖共享就绪队列和全局扫描，容易引入锁竞争和不确定执行路径。硬实时系统要求调度过程具有可证明上界，因此需要局部化、固定化的调度结构。

## 发明内容
本发明采用每 CPU 独立的优先级位图和就绪链表，将线程调度限制在本地分区内完成，利用位图快速定位最高优先级线程，并通过固定的队列结构完成入队、出队和切换。

本发明的有益效果在于：
1. 调度选择路径固定且 O(1)。
2. 降低跨核共享竞争。
3. 提高硬实时场景下的最坏时延可分析性。

## 具体实施方式
在一种实施方式中，每个 CPU 维护 256 级优先级位图和对应优先级链表。调度时，仅在本 CPU 队列内执行位图查找，找到最高优先级非空链表后选取链表头线程作为下一执行对象。若当前无可运行线程，则切换到本 CPU idle 线程。该方法不依赖全局 ready queue，从而避免全局扫描。

## 权利要求骨架
1. 一种面向硬实时微内核的按 CPU 分区固定优先级位图调度方法，其特征在于，每个 CPU 维护独立优先级位图和本地就绪链表。
2. 根据权利要求1所述的方法，其中优先级查找仅在本地队列中执行。
3. 根据权利要求1所述的方法，其中调度路径为 O(1) 固定上界。
4. 根据权利要求1所述的方法，其中 idle 线程作为本地无任务时的兜底执行对象。
