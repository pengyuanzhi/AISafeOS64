## 🎯 技术亮点

### 1. 模块化设计

```
services/vmm/
├── core/          # vCPU/VM 核心模块
├── npt/           # 嵌套页表模块
├── vgic/          # 虚拟 GIC 模块
├── device/        # VirtIO 设备模块
├── hypercall/     # Hypercall 处理模块
├── exit/          # VM 退出处理模块
└── stats/         # 统计信息模块
```

### 2. 二阶段地址翻译

```
Guest VA → NPT 查找 → Guest PA → 提取 Host PA → Host PA
  [47:12]       [L3]        [47:12]     [47:12]       [47:12]
```

### 3. VM 退出分发器

```
ESR_EL2 (退出原因)
    │
    ▼
EC (异常类) = 0x01/0x08/0x06/0x0A/0x0E
    │
    ▼
┌─────────────────────────────────────┐
│ switch (ec) {                       │
│   case 0x01: exit_wfi_wfe();        │
│   case 0x08: exit_hypercall();      │
│   case 0x06: exit_sysreg();         │
│   case 0x0E: exit_inst_abort();     │
│   case 0x0A: exit_data_abort();     │
│ }                                   │
└─────────────────────────────────────┘
```

### 4. VirtIO 鹰kick 机制

```
Guest Kick (写队列通知寄存器)
    │
    ▼
vmm_virtio_kick()
    │
    ▼
恢复队列状态（BLOCKED → SUSPENDED）
    │
    ▼
注入虚拟中断（到 vCPU）
    │
    ▼
VM 退出（HVC → 调度器唤醒）
```
